# Sistema de Oficina Mecânica

## Modelando a entidade Cliente

Além de nome, e-mail e senha, vou guardar algumas informações do cliente e do veículo.

- Modelo do veículo
- Marca do veículo
- Placa do veículo
- Ano do veículo
- Telefone do cliente
- Observações sobre o veículo

A placa vai ser usada para identificar o veículo e o telefone será uma forma de contato além do e-mail.

Também vou guardar observações sobre o veículo, pois é uma informação que pode ser útil em uma oficina.
